 # 🛡️ Cybersecurity Research & Development Projects

  Welcome to my professional security Projects I am a 3rd-year Computer Science & Engineering (CSE) student focusing on the intersection of **Software
  Engineering** and **Offensive Security**.

  This repository serves as a technical demonstration of my ability to identify, exploit, and—most importantly—**remediate** critical security
  vulnerabilities.

  ---

  ## 🚀 Project Catalog

  ### 📂 [Vulnerable-Web-App](./Vulnerable-Web-App) | 🏰 The Magic Library
  **Category:** Application Security (AppSec) / Secure Coding
  **The Challenge:** Many modern applications are still vulnerable to "Injection" attacks due to poor input validation.
  **What's inside:**
  - **Vulnerable PoC:** A Flask application that allows an attacker to dump a database using SQL Injection (SQLi).
  - **Secure Implementation:** A rewritten version using Parameterized Queries to neutralize the attack vector.
  - **Educational Angle:** A side-by-side comparison of "Bad Code" vs "Good Code."
  **🛠️ Key Skills:** `Python`, `Flask`, `SQLite`, `OWASP Top 10`, `Input Validation`.

  ---

  ### 📂 [Subdomain-Finder](./Subdomain-Finder) | 🔍 The Digital Treasure Map
  **Category:** Network Reconnaissance / OSINT
  **The Challenge:** The "Attack Surface" of a company is often larger than it appears. Hidden subdomains often host forgotten, insecure development
  servers.
  **What's inside:**
  - **Automated Scanner:** A Python tool that performs dictionary-based DNS reconnaissance.
  - **Efficiency Logic:** Implementation of request timeouts and error handling to ensure stable scanning.
  - **Educational Angle:** Demonstrates the first phase of the Cyber Kill Chain: **Reconnaissance**.
  **🛠️ Key Skills:** `Python`, `HTTP Protocols`, `DNS`, `Network Automation`, `Requests Library`.
